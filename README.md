# UniversalOffice

Webベースのオフィスアプリです。PC・Android・iPadなど、ブラウザがあればどこでも同じものが動くことを目指しています（PWA対応）。

ワードプロセッサではmd書式のuwpファイルとcsv形式保存のスプレッドシート編集機能を搭載します。また、出力にはpdf等の出力にも対応予定。

## ワードプロセッサ（Word 風 UI）

元は Microsoft Word です。青いタイトルバー＋タブ式リボン＋A4ページで作っています。

- 左上の「ホーム」（Word の「ファイル」の位置）から、アプリ切り替え（ワードプロセッサ／スプレッドシート）とファイル操作（新規／開く／保存／印刷）
- リボンのタブ：書式／挿入／レイアウト／表示（グループ名つき）
  - 書式：スタイル（標準／見出し1〜3／引用）、フォント、サイズ（pt）、太字・斜体・下線・取り消し線、文字色、蛍光ペン、揃え、箇条書き
  - 挿入：画像（ファイル／URL）、表（3×3、行・列の追加／削除）、罫線
  - レイアウト：用紙（A4／B5／レター）、向き（縦／横）、余白（標準／狭い／広い）
  - 表示：ズーム（50〜150%）、ルーラーの表示／非表示
- ルーラー（cm）、ステータスバー（段落数・文字数・用紙・ズーム）
- レスポンシブ対応：狭い画面ではページが幅いっぱいになり、リボンやホーム画面が縦並びになります
- 元に戻す／やり直し（タイトルバーのクイックアクセス）、自動保存（ブラウザの localStorage。サーバーには送信されません）
- 開ける形式：`.docx`（Word）／`.md`／`.html`／`.txt`
- 保存形式：`.docx`／`.md`／`.html`／`.txt`、PDF は印刷画面（用紙・余白の設定が反映されます）から

GitHub Pages では `docs/` フォルダのビルド済みを公開しています（ソースを更新したら `docs/` も再ビルドして一緒にコミットしてください）。

## スプレッドシート

- セルのグリッド編集、行・列の追加、選択行・列の削除、列での昇順／降順ソート
- **数式対応**：`=B2*C2` のような四則演算・括弧・セル参照と、SUM / AVERAGE / MIN / MAX / COUNT（範囲は `A1:B5`）
- 数式バー（選択セルのアドレス＋内容を編集）、選択列の合計表示、先頭行の固定
- `.csv` の読み込み、保存は計算結果の値で書き出し、PDF出力（印刷）
- シートの内容は自動で端末内に保存されます

## 端末内保存とファイル管理（PWA）

クラウドは使わず、すべて端末内（IndexedDB）に保存します。

- 「ホーム」画面にファイル管理があり、名前とフォルダを付けて保存できます
- フォルダを作って整理でき、フォルダで絞り込み表示ができます
- ワードプロセッサとスプレッドシートのファイルを混ぜて一覧でき、相手のアプリで開くこともできます
- PWA としてインストールでき、オフラインでも動きます（Service Worker）

## 開発

言語・構成：TypeScript + React + Vite

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果の確認
```

ファイルはすべてブラウザ内で処理され、サーバーに送信されません。
