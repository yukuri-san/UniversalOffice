# WebX（旧 UniversalOffice）

ブラウザで動く OS 風スイートです。デスクトップにアイコンが並び、アプリはウィンドウで開きます。
ワードプロセッサとスプレッドシートから始まり、マルチウィンドウのデスクトップ環境、アプリストア、BIOS 風セットアップや回復環境、コマンドライン、開発者環境まで備えた「Web の中の OS」です。

**使う**：https://yukuri-san.github.io/UniversalOffice/
Android の Chrome から開けば「アプリをインストール」で PWA としてインストールでき、オフラインでも動きます。iPad / iPhone ではホーム画面に追加して使えます。

- 現在のバージョン：v1.55.1（[変更履歴](CHANGELOG.md)）
- 使い方：[取扱説明書](MANUAL.md)（アプリ内にも「取扱説明書」アプリがあります）
- 構成・開発：[ARCHITECTURE.md](ARCHITECTURE.md)
- ライセンス：[Apache License 2.0](LICENSE)

## 特徴

- **クラウドなし・端末内保存**：ドキュメント・予定・設定はすべて端末内（OPFS 優先／IndexedDB）に保存され、外部サーバーへ送信されません。バックアップは JSON ファイルで書き出し／読み込みできます
- **2つの UI システム**：デスクトップ型の DXUI と、モバイル型の MXUI（Classic＝Android 風／Liquid＝iOS 風ドック）。画面幅で自動切替、設定で固定も可能
- **アプリストア**：130 本のアプリ／ゲームを個別にインストール・アンインストール・更新（本体の更新とは独立）
- **本物の OS らしさ**：ロック画面（PIN）、電源メニュー、仮想デスクトップ×3、コントロールセンター、スクリーンセーバー、クリップボード履歴、ウィジェット、BIOS 風セットアップ、回復環境
- **コマンドライン**：DOS／Windows CMD 風コマンドでファイル操作やアプリ起動、OS 操作までできるコマンドプロンプト
- **開発者環境**：JS／HTML プレイグラウンドと、自分で HTML アプリを作ってデスクトップに置ける「マイApp」
- **16 テーマ × 8 言語**：ライト／ダーク／往年の OS 風テーマなど 16 種、UI は 8 言語対応
- **3つのエディション**：Lite（ストアアプリ無効の軽量版）／Standard（標準）／Pro（初期アプリ限定・プロダクトキー必須、不足分はストアから追加）。設定から切り替え可能

## ストアアプリ（130 本）

ゲーム 43 本／ツール 33 本／計算・変換 20 本／暮らし 23 本／学習 11 本の 5 カテゴリ。

- ゲーム：テトリス／スイカゲーム／2048／数独などの定番に、ライツアウト、マスターマインド、雑学・国旗クイズ、数字記憶、風船割りなど
- **タイピング**：回転寿司のレーンを流れる皿をローマ字で打ち取る「寿司打」風モード（コース制：お手軽 ¥3,000／お勧め ¥5,000／高級 ¥10,000）。単語 406 件＋短文 89 件を収録し、ローマ字の表記揺れ（shi／si など）に対応
- **メディア変換**：FFmpeg（WASM）で動画を GIF／音声（MP3）／WebM に変換。変換は端末内で処理（初回のみエンジン取得にネット接続が必要）
- ツール：水平器／コンパス／騒音計／速度テスト、QR・バーコード、JSON 整形、Base64 変換、あみだくじ、チーム分け、ボイスレコーダーなど
- 暮らし：日記、天気、ギャラリー、ミュージック、家計簿、習慣トラッカー、TODO リスト、読書・映画記録、サブスク管理など
- 学習：九九、計算ドリル、英単語・都道府県・元素記号・漢字読みなどのクイズ系
- 計算・変換：単位変換、通貨変換（最新レート取得つき）、ローン計算、進数変換、税込・割引計算など

## コマンドプロンプト

`help` で一覧。DOS／CMD 風コマンドで WebX の保存ファイルをそのままファイルシステムとして操作できます。

- ファイル：`dir` `cd` `tree` `type` `copy` `move` `ren` `del` `mkdir`、`echo 文字 > file.txt` で作成も
- WebX 操作：`open <アプリ>`、`theme`、`notify`、`sysinfo`、`storage`、`events`、`lock`、`reboot`、`bios`、`recovery`
- 計算：`calc (3+4)*2`

回復環境にも同じ基盤の回復コンソールがあり、`reset-settings` や `clear-cache` が使えます。

## BIOS と回復環境

- 起動スプラッシュで「DEL — セットアップ（BIOS）」から BIOS 風セットアップへ。タブ構成（Main／Advanced／Boot／Security／Diagnostics／Exit）で、起動ロゴ時間、高速ブート、既定のブート先、セーフモード、BIOS パスワード（PIN 連動）、メモリ／ストレージ診断ができます
- 電源メニューから回復環境へ。通常起動、セーフモード、設定だけリセット、バックアップ入出力、復旧ポイント（設定スナップショット最大 3 件）、データ管理、ネットワークテスト、回復コンソール、診断ログ、工場出荷状態への初期化

## データとプライバシー

- 保存先は端末内のみ（OPFS／IndexedDB／localStorage）。アカウント登録もクラウド同期もありません
- 初期セットアップで「通知」「永続化」「端末情報の利用」の許可を確認します。端末情報の利用を切ると、システム情報や一部のウィジェットでハードウェア値を表示しません
- 天気・YouTube・速度テストなど、外部サービスを使うアプリはその通信先にのみ接続します

## バージョンの付け方

- ちゃんとしたシステム更新：マイナーを +1（例：1.21.0 → 1.22.0）
- 細かい修正：末尾に英字（例：1.22.0a → 1.22.0b）。特別版は `ex` のような接尾辞
- ストアアプリの更新：本体バージョンは上げず、ストアでアプリごとに個別更新
