# WebX（旧 UniversalOffice）

ブラウザで動く OS 風スイートです。デスクトップにアイコンが並び、アプリはウィンドウで開きます。
フローティングのガラス風タスクバー（Liquid Glass 風）、スタートメニュー、時計ウィジェット、通知センター、ゴミ箱まで備えた「Web の中の OS」です。

**使う**：https://yukuri-san.github.io/UniversalOffice/
Android の Chrome から開けば「アプリをインストール」で PWA としてインストールでき、オフラインでも動きます。

- 現在のバージョン：v1.8.0（[変更履歴](CHANGELOG.md)）
- ライセンス：[MIT](LICENSE)

## OS の仕組み

- ウィンドウ：ドラッグ移動、最小化・最大化・閉じる（Windows 風ボタン）、タスクバーでの切り替え、画面端へのスナップ（上端で最大化、左右で半分）。狭い画面では自動で全画面
- スタートメニューと右クリックメニュー（デスクトップ）
- 通知センター：タスクバーのベルに出来事が溜まる
- ゴミ箱：削除はまずゴミ箱へ。復元・完全削除ができ、30日たつと自動で完全削除
- 起動スプラッシュ、時計ウィジェット
- キーボードショートカット：環境（Windows / macOS / iPadOS / Android）を判定し、Mod キー（Windows は Ctrl、Mac・iPad は ⌘）を自動で切り替え。Mod+1〜9 でアプリ起動、Mod+Tab でウィンドウ切り替え、Mod+M 最小化、Mod+Shift+M 最大化、Mod+Shift+W 閉じる、Mod+/ で一覧

## アプリ（14＋2）

- **ワードプロセッサ**：Word 風 UI（後述）
- **スプレッドシート**：数式つき表計算、CSV 入出力
- **メモ帳**：複数メモ、自動保存
- **カレンダー**：月表示、予定の追加・削除
- **ブラウザ**：簡易ブラウザ（埋め込み不可のサイトは外部で開く導線つき）
- **YouTube**：公式埋め込みプレイヤーで再生する専用アプリ（URL／動画 ID、履歴つき）
- **エクスプローラー**：ストレージ情報とファイル管理、バックアップ
- **ゴミ箱**：削除したファイルの復元・完全削除
- **電卓**：四則演算と計算履歴
- **時計**：世界時計・ストップウォッチ・タイマー（終了時に通知）
- **ペイント**：レイヤー・図形・塗りつぶし・スポイト・画像読み込み対応の高機能お絵描き。PNG 保存と「壁紙にする」が可能
- **ターミナル**：help / apps / open / storage などのコマンドで OS を操作
- **設定**：言語・テーマ・壁紙・ストレージ
- **ドキュメント**（設定から開く）：LICENSE・README・変更履歴をアプリ内で表示
- **WebX について**（スタート／設定から開く）：バージョンとエディションの専用ウィンドウ

各アプリ左上の「ホーム」（Word の「ファイル」の位置）からもアプリを切り替えられます。

## 設定（多言語・テーマ・壁紙）

- 言語：日本語 / English / 简体中文 / 한국어 / ไทย（シェル＋アプリ内 UI に対応）
- テーマ：ライト / ダーク / iPadOS 27 / macOS 27 / Windows 11 / Windows 7 / Windows XP / Windows 95
- 壁紙：プリセット6種（オーロラ・夕焼け・海・森・桜・モノクローム）＋カスタム画像（自動で縮小して保存）

## 保存と容量対策

データはすべて端末内に保存され、サーバーには送信されません。

- 保存方式は **OPFS 優先**（大容量・高速）。書き込みは一部環境で必要な **Web Worker 経由**をまず試し、ダメならメインスレッド、それもダメなら IndexedDB に自動で切り替える
- 起動時に永続化（ブラウザに自動で消されにくくする設定）をリクエスト
- 旧データ（IndexedDB）は初回に自動で OPFS へ移行（元のデータは消さない）
- エクスプローラーで使用量（実測）・保存方式・ファイル数を確認でき、**バックアップの書き出し／復元**（JSON）で端末の外にも控えを残せる

## ワードプロセッサ（Word 風 UI）

元は Microsoft Word です。青いタイトルバー＋タブ式リボン＋A4ページで作っています。

- リボンのタブ：書式／挿入／レイアウト／表示（グループ名つき）
  - 書式：スタイル（本文／見出し1〜3／引用）、フォント、サイズ（pt）、太字・斜体・下線・取り消し線、文字色、蛍光ペン、上付き／下付き、文字間隔、揃え、箇条書き・番号リスト、行間、段落前後の間隔、字下げ、検索・置換、アウトライン
  - 挿入：画像（ファイル／URL）、表（行・列の追加／削除）、罫線、リンク
  - レイアウト：用紙（A4／B5／レター）、向き（縦／横）、余白、文書の既定（フォント／サイズ／行間）
  - 表示：ズーム、ルーラー、アウトライン表示
- ルーラー（cm）、ステータスバー（段落数・文字数・用紙・ズーム）
- ズームしても改行位置が変わらない方式、自動保存（端末内）
- 開ける形式：`.docx`（Word）／`.md`／`.html`／`.txt`
- 保存形式：`.docx`／`.md`／`.html`／`.txt`、PDF は印刷画面（用紙・余白の設定が反映）から

当初の目標だった「md書式のuwpファイルとcsv形式保存のスプレッドシート編集機能」「pdf等の出力」もここに含まれています。

## スプレッドシート

- セルのグリッド編集、行・列の追加、選択行・列の削除、列での昇順／降順ソート
- **数式対応**：`=B2*C2` のような四則演算・括弧・セル参照と、SUM / AVERAGE / MIN / MAX / COUNT（範囲は `A1:B5`）
- 数式バー、選択列の合計表示、先頭行の固定
- `.csv` の読み込み、保存は計算結果の値で書き出し、PDF 出力（印刷）
- シートの内容は自動で端末内に保存

## 開発

言語・構成：TypeScript + React + Vite（エディタは TipTap、保存は OPFS / IndexedDB）

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果の確認
```

GitHub Pages では `docs/` フォルダのビルド済みを公開しています（ソースを更新したら `docs/` も再ビルドして一緒にコミットしてください）。

ファイルはすべてブラウザ内で処理され、サーバーに送信されません。
